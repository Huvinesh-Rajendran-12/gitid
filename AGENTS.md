# AGENTS

User preferences for this repository:

1. Keep implementations minimal (lowest practical LOC).
2. Avoid bloat and unnecessary abstractions.
3. Prefer simple, direct solutions over broad scaffolding.
4. Think harder before coding to choose the smallest robust approach.
5. Keep README roadmap/checkpoint progress updated as work advances.
6. Provide short progress updates with: Completed / Risks / Next.
7. Run `amp review` for code review before finalizing significant changes and report findings.
